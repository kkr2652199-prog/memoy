## 0. 한 줄

뼈대(입력 `draw_no < t` → 뇌 → 세트 → 채점)는 처음부터 정직했다.  
버그는 **당첨번호를 넣는 컨닝이 아니라, 시간·캐시·점수 눈금이 거짓을 만든 것**이다.  
오늘까지 A~H를 고친 뒤에도, **화면이 구 아카이브를 현재 예측처럼 보여주는 구멍**이 남아 있어 F-M으로 막았다.

---

## 1. 개발 초기 뇌가 하려던 일 (뼈대)

```
과거 회차만 읽는다 (draw_no < 이번)
  → stat 빈도 · markov 전이 · llm 문장 · lstm 시퀀스
  → fusion이 가중 합
  → (선택) hyena / lead1 이 5게임을 다시 고름
  → 추첨 후 겹친 개수만 채점. 번호는 안 바꿈
```

이 순서는 지금도 같다. 로또 6/45는 회차 독립이라, 이 뼈대는 **분석기**이지 1등 기계가 아니다.

초기 특징 (의도):

| 뇌 | 원래 역할 |
|----|-----------|
| stat | 자주/오래 안 나온 번호 |
| markov | 직전 회차 다음에 잘 따라오던 번호 |
| llm | 문장으로 조합 (지금은 HOLD → 통계 대체) |
| lstm | 회차 흐름의 경향 |
| fusion | 위 벡터를 섞음 |
| hyena | 합의 메타 (지금은 OFF) |
| lead1 | 5뇌 25게임을 덮는 5게임 |

## 2. 버그가 생긴 층 (컨닝기 아님)

입력 SQL에 당첨 6개를 넣는 코드는 **없다.**  
거짓이 난 층:

1. **시간** — 추첨 후에 만든 조합을 실력처럼 표시. LSTM이 미래 길이로 학습된 가중치를 과거에 재사용.
2. **캐시** — 한 번 저장된 행을 공식 바꿔도 그대로 돌려줌.
3. **눈금** — confidence 80이 실력이 아님. 5게임이 번호 7개로 붕괴.
4. **가중치** — 그 거짓 성적으로 fusion 비율이 뒤집힘.

## 3. 오늘까지 고친 것 (A~H)과 오늘 막은 것 (L/M)

이미 고침: 시점 게이트, 백테가 운영 가중치 못 덮음, 명예의전당 live, T-GATE 채점, HOLD 태그, wheel, confidence 40~85, entropy 부호, 동점 풀 분산, stat/markov PMF 단일, pool 18, tier1 복붙 제거.

**오늘 실측 DB**

| 항목 | 값 |
|------|-----|
| MAX(draw_no) | **1239** (2026-08-29) |
| 가중치 | 시드 그대로 stat 2.0 / markov 1.5 / lstm 1.0 / llm 0.5 / hyena 0.5, last_updated_draw=**0** |
| T-GATE 행 | **0** (전 회차 백테 아직 없음) |
| 구 1등 | **10건 유지** (formula 빈 문자열) |

**F-L:** 문서가 1232/1234로 남아 있던 이슈. 운영 SSOT는 이미 1239. FINDINGS를 실측에 맞춤.

**F-M (오늘 코드):** 감사에서 확인한 잔여 구멍.

1. 화면 예측 API가 `force_regenerate=False`면 **구 아카이브만 있어도 캐시 hit** → 04월 1등이 현재 예측처럼 보임.  
   → 이제 **T-GATE 5뇌가 완비일 때만** 캐시. 응답 SELECT도 T-GATE만. 생성 시 구행 삭제 안 함.
2. 백테용 짧은 LSTM이 메모리에 남은 채 실전/2·3군 `get_lstm_prob_vector`에 재사용.  
   → ephemeral 모델은 메모리 단기리턴 금지. 공식 ckpt를 다시 봄.
3. Hedge 집계가 formula_id를 안 봄 → 구 1등이 가중치 신호로 섞일 수 있음.  
   → T-GATE만. lead1 존재 여부 COUNT도 T-GATE만.

검증: `python -m app.lotto._test_tgate_ml6` → OK

## 4. 지금 1군 프로세스 (패치 후)

```
POST /predict/n
  1. 이 회차에 T-GATE 행이 5뇌×5세트 있으면 → 그것만 반환 (구행 안 섞음)
  2. 없으면 구행은 두고 T-GATE만 생성
  3. draws = draw_no < n
  4. stat → markov → llm(HOLD면 llm_fallback=통계복사) → lstm → fusion
  5. hyena OFF → 스킵
  6. INSERT formula_id=T-GATE-ML6
  7. lead1: T-GATE 25게임을 읽어 wheel 5게임 (HOLD면 llm 슬롯 제외)
  8. 당첨이 있으면 겹친 개수만 기록. 번호 불변
```

세트: 가중 상위 18(동점이면 1~45 분산) → wheel 5게임. 난수 경로 OFF.

fusion 가중: DB 시드. lstm이 균등이면 lstm 제외. HOLD면 llm 제외.

## 5. 아직 코드 버그가 아닌 것 / 백테 후에만 아는 것

- **전 회차 백테 미실행** → T-GATE 성적 없음. “정직해진 1군이 몇 개 맞히나”는 아직 미확인.

- 2·3군이 1군 lstm/stat/entropy를 import. 1군 패치가 거기로 흐름. 파일은 안 고침.
