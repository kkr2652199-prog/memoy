## 한 줄

**당첨 6번호를 직접 넣는 구조는 아니다.**  
**다만 LSTM 전역 체크포인트 + 캐시 + 가중치 때문에 “과거 회차를 다시 예측하면 미래를 볼 수 있는 구조”다.**

실전 N+1(아직 안 나온 회차)만 새로 돌리면 입력은 정직하다.  
어제 분석한 1~3등 181건은 그 구멍으로 나온 백테 기록이다.

---

## 1. 정직한 층 (컨닝 불가)

`run_prediction` → `_get_draws_before(target)`:

```sql
SELECT * FROM lotto_draws WHERE draw_no < ? ORDER BY draw_no
```

- 이번 회차 당첨번호를 **입력으로 안 넣음**
- stat / markov 벡터는 이 draws만 집계 → **구조적으로 당회차 컨닝 불가**
- 실전 1232~1235(추첨 전 생성) 1~3등 0건과 맞음

---

## 2. 컨닝이 되는 층 (구조 구멍)

### 구멍 1 — LSTM 전역 ckpt (핵심)

`predict_lstm.py` `_ensure_model_ready`:

- 디스크 `lstm_lotto.pt`의 `last_trained_on`을 전역 `_MODEL`로 로드
- **재학습 조건:** `n_draws - last_trained_on >= 50` 일 때만
- **과거 회차 재예측** (`n_draws` < ckpt 길이)이면 재학습 **안 함** → 미래를 본 모델을 그대로 씀

현재 ckpt: `last_trained_on=1226`  
→ 1226 이전 회차를 다시 예측하면 **1226까지 본 뇌**로 과거를 맞춤.

STEP1: lstm DB 1.92 vs WF clean 0.77 (약 2.5배).

### 구멍 2 — fusion / hyena가 lstm을 먹음

- `fusion.py`: `get_lstm_prob_vector(draws)` + `lotto_brain_weights` (lstm 가중 33.5)
- hyena: 5뇌 세트 합의 (lstm 세트 포함)

lstm이 새면 fusion·hyena도 샌다. 1등 10건이 이 3뇌에만 있는 이유.

### 구멍 3 — 캐시 (1회 실행 원칙)

`run_prediction`에 이미 행이 있으면 **재생성 없이 반환**.  
2026-04 백테로 넣은 누수 세트가 그대로 명예의전당에 남음.

### 구멍 4 — 백테가 운영 가중치를 덮음

`run_backtest` → `update_brain_weights(..., eta=1.5)`  
누수 성적(lstm 높음)이 `lotto_brain_weights`에 남고, fusion이 그걸 계속 사용.

### 구멍 5 — 시간 게이트 없음

당첨이 이미 DB에 있어도 `POST /predict/{n}`을 막지 않음.  
과거 회차 재실행 = 시간 컨닝 가능 (번호 직접 주입은 아니지만, 구멍 1과 결합되면 성적 조작).

---

## 3. “지금은 컨닝하냐” (실전 N+1)

| 상황 | 컨닝? |
|------|--------|
| 다음 회차만 새로 예측, draws = 1~MAX | 입력 **정직**. LSTM은 낡은 ckpt(1226)라 성능만 이상하지, 당회차 번호는 못 봄 |
| 과거 회차 재예측 / 백테 / 캐시 조회 | **구조적으로 컨닝 가능** (구멍 1~4) |
| UI 1~3등 181건 | 이미 구멍으로 나온 **백테 잔상** |

## 4. 뇌별

| 뇌 | 당회차 번호 직접 사용 | 구조 누수 |
|----|----------------------|-----------|
| stat | 불가 | 없음 (정직축) |

| lead1 | 불가 | 같은 회차 5뇌 세트만 읽음. 5뇌가 새면 따라 샘 |

## 5. 형에게

**“1군이 컨닝 구조냐?”**  
→ **입구(당첨번호 주입)는 막혀 있고, 창고(LSTM ckpt·캐시·가중치)는 열려 있다.**

고치려면 (패치 안 함 · ID 지시 대기):

1. LSTM: 회차마다 `draws`만으로 in-memory 학습, 전역 ckpt 금지 (또는 `last_trained_on > n_draws`면 무조건 재학습)
2. 과거 회차 `POST /predict` 거부 또는 캐시 무시 옵션
3. 백테가 `lotto_brain_weights`를 못 건드치게 분리
4. 명예의전당에서 백테 구간(created 2026-04) 제외

F-E / F-H / 본 구멍1이 같은 뿌리.
