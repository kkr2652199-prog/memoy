## 2. 예측 프로세스 (코드 경로, 랜덤 아님)

`POST /predict/{n}` → `engine.run_prediction`:

```
1. 캐시: 해당 회차 행이 있으면 재생성 없이 반환 (F-H)
2. draws = _get_draws_before(n)     -- SQL: draw_no < n   (정직)
3. stat     빈도·미출·페어 가중 → top-k 5세트
4. markov   1-step 전이 집계 → top-k 5세트
5. llm      LOTTO_LLM_HOLD=True → stat 복사, 태그만 llm (F-D)
6. lstm     전역 ckpt PMF → top-k 5세트 (구멍)
7. fusion   stat+markov+llm+lstm 가중합 + entropy → top-k 5세트
8. hyena    플래그 OFF → 스킵
9. INSERT 후 당첨이 있으면 matched_count만 채점 (번호를 바꾸지 않음)
10. lead1    5뇌 25세트를 읽어 wheel 5세트 (생성에 당회차 당첨 미사용)
```

세트 조립은 `deterministic_sets.build_weighted_topk_sets`: 가중 상위 **18개**에서 6개 조합을 점수순으로 고른다. `random.choices` 경로는 플래그가 꺼져 있어 **현재 운영 경로는 난수 추첨이 아니다.**

뇌별 역할:

| 뇌 | 지금 하는 일 | 시스템인가 | 역할 수행? |
|----|--------------|------------|------------|
| stat | 과거 빈도·최근성·미출 | 예 (휴리스틱) | **수행.** 실력≈랜덤 0.82 |
| markov | 직전 6번호→다음 전이 | 예 | **수행.** 실력≈랜덤 0.82 |
| llm | HOLD라 stat 복제 | 가짜 뇌 | **못 함** (F-D) |
| lstm | 시퀀스 PMF. ckpt 1226 재사용 | 예 + **누수** | 과거 재예측은 컨닝, 실전 N+1은 낡은 모델 |
| fusion | 4벡터 혼합 | 예 | lstm/가중치에 종속 → **오염된 합의** |
| hyena | 5뇌 합의 | 꺼짐 | **신규 역할 없음** |
| lead1 | 5뇌 커버리지 wheel | 예 | 하위 뇌가 거짓이면 같이 흔들림 |

**결론:** 단순 랜덤이 아니다. 통계·전이·앙상블·결정론 top-k로 만든 시스템이다. 다만 로또 6/45는 회차 독립이라, 이 시스템은 **패턴을 읽는 분석기**이지 난수를 깨는 예측기가 아니다.

## 3. 컨닝 100% 정밀 분해

컨닝을 세 층으로 나눈다. “당첨번호를 세트에 넣는 치트”와 “미래를 보고 과거를 맞춘 것처럼 보이게 하는 구멍”은 다르다.

### 층 0 — 번호 주입 치트 → **없음 (코드)**

생성 함수(`_statistical_predict`, `_markov_predict`, `get_lstm_prob_vector`, `_vector_fusion_predict`, `compute_brain7_sets`)는 `_get_draws_before` / 5뇌 세트만 본다.  
`actual` 6번호는 `INSERT` **이후** `matched_count` 채점에만 쓰인다 (`engine.py` 411~434, `predict_brain7._score_rows_if_actual`).

lead1 기여도 이력은 `target_draw_no 미만`만 (`_build_contribution_history`).

### 층 A — 시간 컨닝 (추첨 후 생성) → **181/181 CONFIRMED**

판정: `created_at` ≥ `draw_date` 20:45.

1등 10건 전부 2026-04-25~26 생성, 추첨일은 2004~2024.  
3등 168건도 동일 백필 구간.

실전 LIVE (추첨 전 생성) **1232~1235: 1~3등 0건.**  
최고: 1235 lead1 **4개**(4등), 1233 stat **3개**(5등).

1236~1239 예측도 추첨일 **이후** 생성 (08-10, 08-18, 08-23, 08-31). 실전으로 세면 안 됨.

### 층 B — 데이터 컨닝 (미래 학습) → **LSTM 전역 ckpt CONFIRMED**

`predict_lstm._ensure_model_ready`:

- 디스크 ckpt `last_trained_on=1226`을 전역 `_MODEL`로 로드
- 재학습은 `n_draws - last_trained_on >= 50` 일 때만
- **과거 회차 재예측** (`n_draws` < 1226)이면 1226까지 본 가중치를 그대로 씀

STEP1 (2026-07-10, 1131~1231): lstm DB avg **1.919** vs walk-forward clean **0.766** (약 2.5배).

fusion/hyena는 lstm 벡터·세트를 먹으므로 1등 10건이 fusion 7 + hyena 2 + lstm 1인 이유와 일치.

### 층 C — 성적 오염이 운영을 오염 → **CONFIRMED**

- `run_backtest`가 매 회차 `update_brain_weights(..., eta=1.5)` (F-E/F-H)
- 당첨 채점 후에도 `data_service` → `maybe_update_brain_weights_after_scoring` (1239 갱신이 이 경로)
- 캐시: 2026-04 백테 1등 행을 재생성 없이 UI에 유지

### 확률로 운이 배제됨

6/45 1등 확률 = 1 / 8,145,060.  
miss/snake 제외 예측 ≈ 41,870세트 → 기대 1등 ≈ **0.005건**. 관측 **10건** ≈ 2,000배.  
5개 일치 기대 ≈ **1.2건**. 관측 2등+3등 **171건**.

반면 **stat 6,050세트 최고 4개, 5개 이상 0.** 기대 5개≈0.17과 맞음 = 정직축.

**판정:** 명예의전당 1~3등은 운이 아니다. 층 A+B.  
실전 N+1의 부진은 층 0이 정직하고, 로또가 독립시행이기 때문이다.

## 4. 어디서부터 뇌가 역할을 못 하나

설계 루프: 확인 → 분석 → 학습 → 진화 → 예측.

| 단계 | 상태 | 끊긴 지점 |
|------|------|-----------|
| 확인 | 동작 | `lotto_draws`, `_get_draws_before` |
| 분석 | 동작 (결함 있음) | entropy 부호 반대(F-B), top-k 붕괴(F-C) |
| 학습 | **오염** | LSTM 전역 ckpt · trap OFF · eta=1.5가 누수 성적 증폭 |
| 진화 | **거짓 성적 추종** | lstm 32 ≫ stat 5.1. hyena OFF인데 가중 27 |
| 예측 | 반쪽 | llm=stat 복제, hyena 스킵, 캐시가 옛 세트 고정 |

역할이 죽은 순서:

1. **2026-04 전수 백테** — 시간 컨닝 기록 대량 INSERT (04-25~27에 3.5만+행)
2. **LSTM ckpt 1226 고정** — 과거 재예측이 미래를 봄. fusion/hyena 2차 오염
3. **Hedge eta=1.5가 그 성적으로 가중치 고정** — 학습이 거꾸로
4. **2026-07 정직화 플래그** — llm HOLD, hyena OFF, trap OFF, N+1 auto OFF → 진화 루프 정지
5. **캐시 1회 실행 원칙** — 거짓 1등이 UI에 남음

최근 1236~1239가 안 맞는 체감 = DB와 일치 (5개 이상 0). 1237 fusion/lstm avg 2.0도 추첨 **후** 생성이라 실전 아님.

## 5. 인터넷·공개 자료와 대조 (변질인가)

검색·문헌은 “1군 코드가 해킹당했는가”가 아니라, **같은 구조가 업계에서 어떻게 분류되는가**를 본다.

| 자료 | 요지 | 1군에 대입 |
|------|------|------------|
| 기재부·서울대 통계연 (정책브리핑, 당첨번호 동등성) | 6/45 추첨 동등성 위배 근거 없음. 독립시행 | 빈도/마르코프가 장기적으로 랜덤≈0.8인 이유 |
| 동행복권 비너스 추첨기 (연합뉴스·한경) | 공기혼합 무작위 추출 | 과거 회차가 다음 공을 물리적으로 못 밈 |
| IBM / Kyle Jones (data leakage, lookahead) | 예측 시점에 없는 미래 정보로 학습하면 백테만 좋아 보임 | LSTM 전역 ckpt = lookahead leakage |
| arXiv 2512.06932 (LSTM time-series leakage) | 분할 전 시퀀스 생성·미래 윈도우가 RMSE를 왜곡 | 1226 ckpt로 310회를 재예측하는 패턴과 동일 계열 |
| PowerPredict 등 공개 로또 ML | 통계+마르코프+LSTM 앙상블을 **엔터테인먼트**로 명시, 예측 불가 고지 | 1군 뇌 구성과 닮음. 설계가 특이한 치트가 아님 |
| kyr0/lotto-ai 등 (DECISION_LOG 2026-07-11 교차) | fancy RNG | 목적 재정의(분석앱)와 일치 |

**변질 판정:** 외부에서 1군에 치트를 심은 흔적은 없다.  
변질은 **우리 백테·ckpt·가중치 루프가 문헌이 경고하는 leakage를 그대로 밟은 것**이다. 2026-04 Layer 3.5 주석(`LSTM 비중 36%→69%`)이 그 방향을 코드에 적어 둔 상태다.

## 6. 구조는 잘 만들었나 · 튜닝으로 역할 회복인가

**잘 만든 부분**

- 컨닝 방지 SQL을 엔진 입구에 둠
- 뇌 분리(brain_tag) + 5세트 + fusion 앙상블
- 정직화 플래그로 랜덤 워크·hyena·trap을 끌 수 있음
- lead1은 당회차 정답을 생성에 안 씀 (이력은 N-1)

**덜 만든·망가뜨린 부분**

- LSTM을 회차 단위 in-memory가 아니라 전역 파일 ckpt로 둠
- 백테가 운영 가중치를 덮음
- confidence 스케일 불일치(F-A), top-k 붕괴(F-C)
- HOLD llm을 별개 뇌처럼 INSERT

**튜닝으로 가능한 것**

- 측정 거짓말 제거 → stat/markov/fusion이 **분석 도구**로 다시 읽힘
- 가중치를 STEP1 정직축에 맞춤 → fusion이 lstm에 안 끌려감
- 캐시 분리 → 명예의전당이 실전처럼 안 보임

**튜닝으로 불가능한 것**

- 1등·2등·3등을 안정적으로 맞춤. 실전 1232~1235가 이미 0건. 서울대 동등성 + 독립시행.

1군 목적은 BOOT 한 줄과 같음: **정직한 분석앱 (당첨 보장 아님).**
