## 0. 명분 공식 (당첨 보장 아님)

이름: **T-GATE-ML6**

일반 자동번호와 다른 점 — 맞춘다고 주장하지 않는다. **왜 이 번호인가**를 시점으로 고정한다.

1. **시점 게이트:** 회차 t의 뇌는 `draw_no < t`만 본다. 미래로 학습한 가중치는 과거 t에 쓰지 않는다.
2. **6/45 다중라벨:** 번호 6개는 서로 배타가 아니다. softmax(합=1) 대신 시그모이드+BCE. 추론 후 PMF로만 정규화.
3. **정직축 혼합:** fusion 시드 stat 2.0 · markov 1.5 · lstm 1.0. 백테 1등이 가중치를 키우지 않는다.
4. **Hedge는 실전만:** `created_at` < 추첨일 20:45. 오늘 실측 live 회차 **4** vs 전체 최근 50.

운은 남는다. 명분은 **난수가 아니라 이 네 줄**이다.

## 1. 순번1 LSTM ckpt (구조구멍)

### 발견·문헌

구코드: `n_draws - last_trained_on >= 50`일 때만 재학습. 310회 재예측에 `last_trained_on=1226`을 그대로 씀.  
Walk-forward는 fold마다 미래 가중치 재사용 금지. Expanding ckpt는 **길이가 줄면 저장 금지**.

추가로 softmax+BCE는 6-of-45에 부적합 (PyTorch: multilabel → BCEWithLogitsLoss).

### 패치 (`predict_lstm.py`)

- `ckpt_usable_for_horizon(n, trained)`: trained > n 이면 사용 금지
- `should_persist_checkpoint`: n < disk_len 이면 저장 금지 (임시 5 epoch)
- ckpt `formula=T-GATE-ML6` 없으면 구 softmax 파일 **로드 거부** (오늘 실측: accepted=False)
- 출력: logits → sigmoid → 정규화 PMF. `pos_weight=39/6`

### 검증

```
ckpt_usable_for_horizon(310, 1226) → False
should_persist_checkpoint(310, 1226) → False
disk T-GATE 로드 → None (구버전 거부)
python -m app.lotto._test_tgate_ml6 → OK
```

첫 실전 `POST /predict` (입력 길이 ≥ 공식 ckpt)는 T-GATE로 30 epoch 학습 후 디스크 저장. 과거 회차 재예측은 임시학습·미저장.
